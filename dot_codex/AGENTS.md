## Computer and Browser Use policy

- Do not use Computer Use, coordinate-based CUA, browser control, browser automation, or DOM automation by default.
- Prefer APIs, CLIs, connectors, and logs.
- One exception is validating UI changes made in code during the current task, when visual or interactive verification is necessary.
- Never use Computer Use, browser control, browser automation, or DOM automation for research, dashboards, data retrieval, authentication, settings, or ordinary browsing.
- Do not use a browser to reuse an existing signed-in session, inspect or obtain session state, or work around missing, expired, or rejected API/CLI credentials. If API or CLI authentication is unavailable, stop and request the required credential or authentication setup.
